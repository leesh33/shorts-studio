# 쇼츠 클론 스튜디오 (Shorts Clone Studio)

예시 쇼츠 URL 하나와 주제 한 줄만 넣으면, 그 영상의 **구조(훅·리듬·컷 수·자막·템포)** 를 읽어서
내 주제로 **쇼츠 대본 · 자막 · 컷별 연출/이미지 프롬프트**를 만들어 주는 웹 앱입니다.

- 라이브: https://shorts-studio.vercel.app
- 스택: 정적 HTML/CSS/JS + Vercel Serverless Function 1개 (빌드 없음, 의존성 없음)

## 이 앱이 고친 것 (이전 검단 숏츠의 아쉬움)

| 이전 문제 | 이 앱의 처리 |
| --- | --- |
| 그림체가 뭉개지고 주제와 안 맞는 AI 카툰 느낌 | 컷마다 **실사 톤 영문 프롬프트**(장면·조명·색보정·렌즈·금지어)를 따로 만듭니다. 미리보기는 사진을 지어내지 않고 무드 그라데이션 + 켄번즈 모션으로 **연출 의도**만 보여줍니다. |
| 목소리가 느리고 늘어짐 | **분당 어절·문장 길이**를 레퍼런스에서 읽어(또는 표준값) 초당 6.2자 기준으로 컷 길이를 계산하고, 미리보기는 Web Speech 1.16~1.30배속으로 읽습니다. 컷 사이 무음 없이 이어 붙습니다. |
| 훅이 약하고 자막이 밋밋함 | 첫 2.8~3초 **훅 전용 컷** + 제목 후보 3개, 자막은 **1~3줄 굵은 문장 + [강조] 키워드 색강조**로 렌더링합니다. |

## 화면

1. **입력** — 예시 쇼츠 URL(프리셋 3개), 주제 한 줄, 말투(자동/정보/썰/리뷰), 길이(30/36/45초),
   선택 사항으로 *레퍼런스 대사*와 *참고 자료(팩트)*.
2. **스튜디오** — 9:16 폰 프레임 플레이어(켄번즈·자막 애니메이션·컷별 진행바·한국어 음성·배속),
   레퍼런스 블루프린트 카드(무엇을 근거로 읽었는지 포함), 컷별 대본 편집, 연출 프롬프트, 내보내기.

## 내보내기

- 전체 스크립트 / 컷별 프롬프트 / TTS 청크 복사
- `.srt` 자막, `.json` 패키지(전체 타임라인·프롬프트·블루프린트), `.html` 스토리보드 내려받기

## API

`POST /api/analyze-and-generate`

```json
{ "url": "https://www.youtube.com/shorts/ID", "topic": "검단신도시 2028년 교통 호재",
  "tone": "auto", "length": 36, "facts": "선택: 확인된 팩트", "referenceText": "선택: 레퍼런스 대사" }
```

응답: `{ ok, analysis: { source, attempts, blueprint }, package }`
`analysis.attempts` 에 어떤 경로로 메타데이터를 가져왔는지 남습니다
(`youtube-page` → `oembed` → `youtube-data-api` 순서, 실패해도 추정으로 계속).

`GET /api/health` → `{ ok, app, hasYoutubeKey, node }`

## 환경변수 (선택)

| 이름 | 있으면 좋아지는 것 |
| --- | --- |
| `YOUTUBE_API_KEY` | 제목·설명·태그·길이를 Data API v3 로 한 번 더 보강 (없으면 영상 페이지 파싱 → oEmbed 로 폴백) |

키가 없어도 앱은 동작합니다. 실패한 업스트림은 `analysis.attempts` 에 이유만 남기고 계속 진행합니다.

## 정직하게 말하는 한계

- **유튜브 자막(대사)은 자동으로 가져오지 않습니다.** 서명된 timedtext 는 데이터센터 IP에서 빈 응답을 주는 경우가 많아,
  대신 *레퍼런스 대사 붙여넣기*로 리듬을 실측합니다. (자동화하려면 자막 API/POT 토큰이 필요합니다.)
- **문장은 템플릿 엔진**이 씁니다. 확인되지 않은 숫자·일정은 지어내지 않고 비워 두고, 컷마다 `확인할 팩트`를 표시합니다.
  LLM으로 문장 품질을 올리려면 `api/analyze-and-generate.js` 의 `generatePackage()` 호출을 LLM 호출로 바꾸면 됩니다.
- **MP4 렌더·AI 이미지 생성·실제 TTS는 없습니다.** 이 앱은 *대본·연출 패키지*까지 만들고, 그 뒤 파이프라인의 입력을 제공합니다.

## 개발

```bash
node tools/serve.mjs     # http://localhost:4310 (정적 + /api 로컬 실행)
node --test tests/       # 엔진 단위 테스트 10개
```

## 구조

```
index.html            입력 화면 + 스튜디오 화면
styles.css            모바일 우선(390px) 다크 스튜디오 UI
app.js                플레이어·컷 편집·내보내기
lib/engine.js         URL 파싱 · 레퍼런스 분석 · 대본 생성 (순수 함수, 브라우저/서버 공용)
api/analyze-and-generate.js   메타데이터 수집 + 분석 + 생성
api/health.js         배포 확인
tests/engine.test.mjs 엔진 테스트
tools/serve.mjs       로컬 미리보기 서버
```
